# 🦁 Safari Kids Adventure — عالم الاستكشاف السحري

تطبيق ويب تعليمي تفاعلي للأطفال (٣–٦ سنوات) على هيئة **مغامرة ولعبة بمكافآت**،
يُعلّم الطفل:

- 🔤 الحروف العربية
- 🔠 الحروف الإنجليزية
- 🔢 الأرقام (عربية + إنجليزية) والعدّ
- 🦁 الحيوانات (أصواتها وأشكالها)
- 🐠 الأسماك
- 🦜 الطيور
- 🍎 الفواكه
- 🎨 الألوان
- ⭐ الأشكال الهندسية

## ✨ المميزات

- خريطة عالم سحري مقسّمة إلى مناطق، كل منطقة تُفتح تدريجياً.
- مرشد لطيف يرافق الطفل في رحلته.
- ألعاب متنوعة: تعلّم بالنطق، اصطياد الحروف، تتبّع/رسم الحرف، العدّ، مطابقة الظل، أصوات الحيوانات.
- نظام مكافآت: نجوم + مجموعة شخصيات وألعاب يجمعها الطفل.
- نطق عربي وإنجليزي واضح عبر متصفح الجهاز.
- مؤثرات صوتية وتشجيع مستمر.
- يعمل دون اتصال بالإنترنت (PWA) ويمكن تثبيته كتطبيق.

## 🛠️ التقنيات

- HTML5 / CSS3 / JavaScript (ES Modules) — بدون أي مكتبات خارجية.
- `Web Speech API` للنطق.
- `Web Audio API` للمؤثرات الصوتية.
- `localStorage` لحفظ التقدّم والمكافآت.
- إيموجي ملوّن بدل الصور (خفيف ويعمل دون اتصال).

## 🚀 التشغيل

التطبيق ملفات ثابتة (Static). يجب تقديمه عبر خادم بسيط (لأن ES Modules
لا تعمل عبر `file://`):

```bash
# أي خادم ثابت، مثل:
python3 -m http.server 8000
# ثم افتح:  http://localhost:8000
```

أو انشره مباشرة على **GitHub Pages**.

## 📁 البنية

```
index.html
css/        أنماط التصميم
js/
  core/     المحرّك (صوت، نطق، تخزين، مكافآت، توجيه)
  data/     محتوى كل منطقة (حروف، أرقام، حيوانات...)
  games/    أنواع الألعاب القابلة لإعادة الاستخدام
  screens/  شاشات التطبيق
  app.js    نقطة البداية
```
