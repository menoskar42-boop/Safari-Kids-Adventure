# 🦁 Safari Kids Adventure — عالم الاستكشاف السحري

تطبيق ويب تعليمي تفاعلي للأطفال (٣–٦ سنوات) على هيئة **مغامرة ولعبة بمكافآت**،
يُعلّم الطفل:

- 🔤 الحروف العربية
- 🔠 الحروف الإنجليزية
- 🔢 الأرقام (عربية + إنجليزية) والعدّ
- 🦁 الحيوانات (أصواتها وأشكالها)
- 🐠 الأسماك
- 🦜 الطيور
- 🍎 الفواكه
- 🎨 الألوان
- ⭐ الأشكال الهندسية

## ✨ المميزات

- خريطة عالم سحري مقسّمة إلى مناطق، كل منطقة تُفتح تدريجياً.
- مرشد لطيف يرافق الطفل في رحلته.
- ألعاب متنوعة: تعلّم بالنطق، اصطياد الحروف، تتبّع/رسم الحرف، العدّ، مطابقة الظل، أصوات الحيوانات.
- نظام مكافآت: نجوم + مجموعة شخصيات وألعاب يجمعها الطفل.
- نطق عربي وإنجليزي واضح عبر متصفح الجهاز.
- مؤثرات صوتية وتشجيع مستمر.
- يعمل دون اتصال بالإنترنت (PWA) ويمكن تثبيته كتطبيق.

## 🛠️ التقنيات

- HTML5 / CSS3 / JavaScript (ES Modules) — بدون أي مكتبات خارجية.
- `Web Speech API` للنطق.
- `Web Audio API` للمؤثرات الصوتية.
- `localStorage` لحفظ التقدّم والمكافآت.
- إيموجي ملوّن بدل الصور (خفيف ويعمل دون اتصال).

## 🚀 التشغيل

التطبيق ملفات ثابتة (Static). يجب تقديمه عبر خادم بسيط (لأن ES Modules
لا تعمل عبر `file://`):

```bash
# أي خادم ثابت، مثل:
python3 -m http.server 8000
# ثم افتح:  http://localhost:8000
```

أو انشره مباشرة على **GitHub Pages** (في هذه الحالة تعمل ميزات النطق عبر
Web Speech فقط، بدون ميزات OpenAI لأنها تحتاج خادماً).

## 🤖 التشغيل على Replit مع OpenAI (موصى به)

يحتوي المشروع على خادم Node صغير (`server/`) يعمل كوسيط آمن لـ OpenAI:
النطق (TTS)، المساعد الصوتي (سؤال/جواب)، والنسخ الصوتي (STT).
**مفتاح OpenAI يبقى على الخادم فقط ولا يصل إلى المتصفح أبداً.**

### الخطوات على Replit
1. استورد المستودع في Replit (Node.js).
2. من قائمة **Tools → Secrets** أضِف سرّاً:
   - المفتاح: `OPENAI_API_KEY`
   - القيمة: مفتاح OpenAI الخاص بك (`sk-...`).
3. اضغط **Run**. سيقوم Replit بتنفيذ `npm install && npm start` تلقائياً
   (مهيّأ في `.replit`).
4. افتح نافذة المعاينة — التطبيق يكتشف الخادم تلقائياً ويفعّل ميزات الـ AI.

> إن لم يوجد المفتاح، يعمل التطبيق كاملاً لكن بنطق Web Speech بدل OpenAI.

### تشغيل محلي مع الخادم
```bash
npm install
cp .env.example .env   # ثم ضع مفتاحك في .env
npm start              # http://localhost:3000
```

### مسارات الخادم
| المسار | الوظيفة |
|---|---|
| `GET /api/health` | هل ميزات الـ AI متاحة؟ |
| `POST /api/tts` | نص → كلام (mp3) |
| `POST /api/ask` | سؤال الطفل → إجابة قصيرة |
| `POST /api/stt` | صوت → نص |

```
  screens/    شاشات التطبيق
  app.js      نقطة البداية
```
